    Command reference

    The werkbord command, for people who like a terminal.

    The local service

    The Mac app installs the werkbord command in ~/.local/bin. Add that folder to your PATH to use it.

    CommandPurpose
    werkbord statusCheck the installed service.
    werkbord startStart the service.
    werkbord stopStop the service. Refuses while agents are working.
    werkbord restartRestart the service.
    werkbord openOpen the board in a browser.
    werkbord open --qrShow a phone sign-in code.
    werkbord doctorCheck setup and dependencies.
    werkbord logs -n 100Read recent service logs.
    werkbord setupRefresh the service’s environment and settings.
    werkbord update --checkCheck for an update.
    werkbord uninstallRemove the service; keep your data.

    Add a project

    Terminal
    werkbord project add ~/code/my-app

    Use the path of a local Git repository.

    Team server

    Terminal
    werkbord-team version
werkbord-team workspace create --name "Acme" --owner "Ada"
werkbord-team serve

    --addr chooses the listening address. WERKBORD_TEAM_DATA_DIR selects the data directory; WERKBORD_TEAM_LOG_LEVEL and WERKBORD_TEAM_LOG_FORMAT control logging. Read Team setup before serving a workspace to other machines.
