    Installation

    Install, update, and manage your local runner.

    The Mac app

    The simplest way on a Mac: download Werkbord.dmg, open it, and drag Werkbord onto Applications. It is one app for Apple Silicon and Intel, for macOS 13 or later, signed with a Developer ID and notarized by Apple, so the first launch shows only the usual question macOS asks about an app from the Internet. From a terminal:

    Terminal
    curl -fL -o Werkbord.dmg https://github.com/micho8cho93/werkbord/releases/latest/download/Werkbord.dmg
open Werkbord.dmg

    The first time you open the app it sets Werkbord up on your computer: the werkbord program in ~/.local/bin, your data and database, and a background service that keeps your agents and schedules running after you close the window. Closing the window or quitting the app never stops them. It is the same Werkbord the command-line installer makes: install one and use the other and you have one installation.

    Keep the app in Applications. To update, choose Werkbord → Check for Updates…, or Update now when Werkbord says a new version is available: the app checks a signature before it installs anything, and your data is backed up before the program is replaced. Updates wait while coding agents are working. Looking for updates can be turned off with "noUpdateCheck": true in config.json.

    Requirements

    The Mac app needs only macOS 13 or later. The command-line installer below needs macOS or Linux, Git, and a signed-in Claude Code or Codex CLI. Run it from a terminal where your agent command works.

    Command line: macOS and Linux

    Terminal
    curl -fsSL https://raw.githubusercontent.com/micho8cho93/werkbord/main/scripts/install.sh | sh

    The installer verifies the release checksum, puts werkbord in ~/.local/bin (with devboard, its earlier name, beside it), and sets up the local database, access token, and user background service. Browser setup handles repositories and optional GitHub integration.

    If your shell cannot find werkbord, add ~/.local/bin to your PATH and open a new terminal.

    Windows

    Native Windows support is experimental. In PowerShell:

    Terminal
    irm https://raw.githubusercontent.com/micho8cho93/werkbord/main/scripts/install.ps1 | iex

    Native Windows does not run the coding agents. To run agents on Windows, use the Linux installer inside WSL with Git and your agent installed there.

    Check your setup

    Terminal
    werkbord status
werkbord doctor
werkbord open

    If the browser opens but agents are missing, run werkbord setup from the terminal where Claude Code or Codex works. The background service needs that environment too.

    Update or remove

    In the Mac app: Werkbord → Check for Updates…. From a terminal:

    Terminal
    werkbord update --check
werkbord update

    Updates create an automatic database backup. Check werkbord status and werkbord doctor after updating.

    werkbord uninstall removes the installed service and binary while preserving your data. Use the command reference for service controls.
