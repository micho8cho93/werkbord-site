Questions before you install

What is Werkbord?

Werkbord is a local-first team workspace for AI agents. People plan and review the work on one board, agents do it in their own Git worktrees, and nothing merges without a person. The board, database and agent sign-ins stay on your own machines.

Who is it for?

Developers use the Mac app today to run agents on their own repositories. Werkbord Team, in early access, adds a shared board where product managers and designers write tickets and sign off from a browser. People who don’t code can already hand file work to an agent, and simpler flows for them are planned.

Werkbord for people who don’t code

Which AI agents does it work with?

Claude Code and Codex today, through their own command-line tools and your own accounts. Werkbord needs no account of its own and never asks for an API key. Only phone access needs an account, a free Tailscale one. Support for other models is planned.

How does a team use it?

Werkbord Team, in early access, is one shared board for tickets, claims, branches and reviews. Each person runs agents on their own machine with their own keys. The Team server only coordinates: it never runs code or holds credentials, and a ticket is not Done until its pull request is merged and a reviewer signs off.

See Werkbord Team

How is it different from running Claude Code or Codex in a terminal?

Same agents, plus what a terminal lacks: a task queue and calendar, several tasks side by side without shared files, one place that shows which agent needs you, and a review step before anything merges. Your existing sign-ins keep working.

See the app tour

Does my code leave my Mac?

Werkbord has no server of its own, so it sends nothing to us. Your agents still talk to their own providers, Anthropic and OpenAI, as they do in a terminal. Phone access runs over your own Tailscale network. A release check asks GitHub for new versions and can be turned off.

What leaves your computer

Can an agent merge my code without asking?

No. Each task works on its own branch in a separate worktree, so your checkout stays untouched. Finished work waits in Review, and only a person can merge it, after a fresh repository check. Permission requests always reach you. Agents run as your macOS user, so this is isolation, not a sandbox.

How review works

Can I use it from my phone?

Yes. Werkbord joins your own Tailscale network, so your phone connects directly and nothing is exposed to the internet. Every request still needs an access token. You need the free Tailscale app on your phone. There is no push relay, so alerts can wait until you open the app.

Connect your phone

Does it keep working when I close the window or my Mac sleeps?

Closing the window or quitting the app stops nothing: Werkbord runs as a background service that starts at login. A sleeping Mac pauses everything, and Werkbord does not keep it awake. Choose whether a missed schedule runs late or is skipped.

Can I schedule work for tonight?

Yes. Give a task an exact time or a place in the queue, and make it wait for another task. The controller starts it without the window or your phone. Each schedule is one attempt, and recurring schedules are not built yet.

Scheduling

What does it run on?

The Mac app needs macOS 13 or later and runs on Apple Silicon and Intel. A command-line installer covers macOS and Linux, and Windows is experimental. You also need Git and the Claude Code or Codex command-line tool.

Installation guide

What if an agent crashes or an update fails?

A crash is recorded and the task’s worktree is kept, so you can inspect it and run again. Before any upgrade that changes the database, Werkbord copies it and keeps the newest five copies, and werkbord db restore --latest brings the newest back.

Backups and recovery

When is Werkbord the wrong tool?

If you need models other than Claude Code and Codex today, recurring schedules, or work that continues while your computer is off, Werkbord is not the right tool yet. It is built for teams who want their agents and code to stay on their own machines.
